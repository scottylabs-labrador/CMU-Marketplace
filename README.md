# CMU Marketplace

A web marketplace for Carnegie Mellon University students to buy and sell items within the CMU community.

## Overview

CMU Marketplace was developed through ScottyLabs as a student-focused marketplace application. The project provides a platform for users to browse listings and interact with marketplace items.

## Tech Stack

* React
* JavaScript
* Node.js / npm

## Running Locally

```bash
npm install
npm start
```

The application will run locally at `http://localhost:3000`.
